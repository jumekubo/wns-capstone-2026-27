How to read this dashboard

Theme groupings are an interpretive first pass. Counts represent distinct explicitly named contributors within each theme, keyed by poster and name; roster identities are not verified. A student can appear in several themes. Unnamed and “All” responses do not increase named-student counts. Connections indicate explicitly named students shared between themes. Groups 1–6 match the teacher-assigned photo filenames; they are brainstorm groups, not necessarily final project teams.

Source wording is preserved with light spelling normalization. Uncertain readings, symbols, and revisions remain in notes. The dashboard is a read-only snapshot of November 3; corrections and future sessions can be incorporated into its source record. Original poster photographs are not included in this public edition.
