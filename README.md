# WNS Capstone Explorer · 2026–27

Interactive dashboard for the November 3, 2026 eighth-grade brainstorms. Includes themes, a connection map, group heatmap, WNS pillars, student profiles, and searchable responses.

This public edition includes first names and transcribed responses with teacher authorization. Original poster photographs and photo links are excluded. The complete local archive remains separate.

Open index.html in a browser. No build or installation is required. For GitHub Pages, select the main branch and root folder in Settings → Pages.

Counts represent distinct explicitly named students per theme. Unnamed and group-wide responses are shown separately. Groups 1–6 follow teacher numbering. DEIB is counted as DEIJ; unfinished academic wording is not counted as Academic Excellence.
